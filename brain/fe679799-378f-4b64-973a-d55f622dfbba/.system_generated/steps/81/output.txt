To enable remote debugging for your browser instance—a required step for connecting AI agents via the **Chrome DevTools MCP (Model Context Protocol)**—follow these steps:

### How to Enable Remote Debugging
1.  **Open your browser** (Chrome, Edge, or other Chromium-based browsers).
2.  In the address bar, navigate to:
    `chrome://inspect/#remote-debugging` 
    *(Use `edge://inspect/#remote-debugging` if you are using Microsoft Edge).*
3.  Locate the checkbox labeled **"Allow remote debugging for this browser instance"** and ensure it is checked.

---

### Why is this necessary?
The **Chrome DevTools MCP** allows AI coding agents (such as Claude Code, Cursor, or other MCP-compatible clients) to interface directly with your live browser session[1][2][3]. 

*   **Access Active Sessions:** By enabling this, you allow your AI agent to "attach" to your current browser profile[4]. This is crucial because it allows the AI to use your existing cookies, saved logins, and active tabs[4][5].
*   **Bridge to Protocol:** The MCP server acts as a bridge, translating high-level commands from the AI (like `navigate_page` or `take_screenshot`) into the **Chrome DevTools Protocol (CDP)**, which controls the browser[3]. 
*   **Automation:** Once enabled, you can configure your MCP client (in VS Code or your terminal) using the `--autoConnect` flag to automatically link the agent to your active browser whenever it runs, avoiding the need to launch a separate, "cold" browser instance[6][4][5].

### Troubleshooting Tips
*   **"Auto-Connect" vs. New Instance:** By default, many MCP configurations may try to launch a fresh, isolated browser[7][5]. If you want the agent to use the browser you are currently using, ensure you have added the `--autoConnect` flag to your MCP server configuration[6][4][5].
*   **Permissions:** When you first connect, your browser may ask for permission to allow the external application to control it. Be sure to accept these prompts to establish the connection[8].
*   **Verification:** You can verify the connection is working by asking your AI agent to "list my open tabs"[9][10]. If it successfully returns the titles of your currently open pages, the setup is correct[9].
