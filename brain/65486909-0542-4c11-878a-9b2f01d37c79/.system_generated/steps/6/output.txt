The search for "install ecc github" returned the following summary:
To install **ECC (Everything Claude Code)**, the recommended and most straightforward method for Claude Code users is to install it as a plugin directly within the agent[1].

### Recommended Installation (Claude Code Plugin)
For most users, you do not need to clone the repository or manually manage files[1]. Instead, run these commands inside your project directory where Claude Code is active[1]:

1.  **Add the plugin:**
    ```bash
    /plugin marketplace add https://github.com/affaan-m/ECC
    ```
2.  **Install the plugin:**
    ```bash
    /plugin install ecc
    ```
3.  **Verify the installation:**
    ```bash
    claude-code-verify
    ```

---

### Important Considerations
*   **Avoid Duplication:** Do not mix installation methods. If you use the plugin method, do not also run CLI-based installers or manual file copies, as this will lead to duplicate skills and rules[1].
*   **Requirements:** Ensure you have **Claude Code 2.1 or newer** installed and available on your PATH[2][1].
*   **Updates:** The ECC GitHub repository (maintained by `affaan-m`) is the primary source of truth[3][1]. Check the [official GitHub repository](https://github.com/affaan-m/ECC) for the latest instructions and support status, as the project evolves quickly[1].

### Other Versions
*   **ECC Tools:** If you are looking for the GitHub App version that integrates with repository history and pull requests, it is available via the [GitHub Marketplace](https://github.com/marketplace/ecc-tools)[4][5].
*   **Other Libraries:** If you were looking for an "ECC" library related to *Subnautica* modding or the *ecCodes* (ECMWF) data library, these are separate projects with their own specific installation requirements (typically via `pip install eccodes` for the latter)[6][7][8].
