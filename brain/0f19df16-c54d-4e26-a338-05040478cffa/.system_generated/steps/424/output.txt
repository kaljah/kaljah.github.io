The **API Compendium of Greenhouse Gas Emissions Methodologies for the Oil and Natural Gas Industry** provides methodologies and emission factors for estimating methane (CH₄) emissions from drilling mud degassing.

In the 2021 edition of the API Compendium, the recommended methane emission factors for onshore drilling mud degassing are:

*   **Water-based mud:** 0.0458 metric tons (mt) CH₄ per drilling day[1].
*   **Oil-based and synthetic muds:** 0.0103 metric tons (mt) CH₄ per drilling day[1].

### Key Contextual Information
*   **Methodology Development:** API has noted that these factors were adjusted from older (1977) estimates to better reflect the borehole sizes and porosity typically associated with modern onshore drilling practices[1].
*   **Methane Content:** The default methane content used in the API Compendium for mud degassing calculations is **65.15 wt.%**, a value based on guidance from the Bureau of Ocean Energy Management (BOEM)[2][3].
*   **Industry Perspective:** API has emphasized that many onshore drilling operations utilize balanced or slightly over-balanced mud systems to prevent gas entrainment, meaning dedicated mud degassing systems are not always necessary or used in the same way they are in offshore environments[4].
*   **Usage:** The API Compendium is widely recognized as a foundational resource for oil and gas companies to estimate and report greenhouse gas emissions[5][6]. However, API often advises that, where possible, users should consider using site-specific or regional data (such as gas composition by NEMS region) to better represent local variability rather than relying solely on default factors[2][3].
